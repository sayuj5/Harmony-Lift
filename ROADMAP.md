# Roadmap

This document outlines the planned features and improvements for Harmony-Lift.

---

## 🟢 Now (v2.0.0 — Shipped)

> *Production-ready release*

- [x] Offline Llama 3.2 1B Local Inference via llama.cpp JNI
- [x] Real-time Pitch Detection (YIN algorithm, < 50ms)
- [x] Chord & Scale Recognition from live audio
- [x] Practice Coach guided sessions
- [x] AI Theory Tutor (offline Q&A)
- [x] DataStore-backed Dark Mode toggle
- [x] Privacy Policy screen
- [x] PDF & TXT practice report export
- [x] WorkManager resumable model download with notifications
- [x] Material Design 3 adaptive UI
- [x] R8 Minification for Release builds
- [x] FileProvider secure share sheet

---

## 🔵 Next (v2.1.0 — Planned Q3 2026)

> *Instrument-specific intelligence*

- [ ] **Guitar Mode** — string/fret position hints, barre chord guidance
- [ ] **Piano/Keyboard Mode** — finger position visualization
- [ ] **Metronome** — integrated tap-tempo metronome with visual beat indicator
- [ ] **Backing Track Generator** — AI-generated simple chord progressions
- [ ] **Streak & XP Persistence** — Room database for long-term progress tracking
- [ ] **Improved Model Download UX** — Estimated time remaining, bandwidth control

---

## 🟡 Future (v3.0.0 — Planned Q1 2027)

> *Advanced learning and community*

- [ ] **MIDI Input Support** — Connect MIDI keyboards and controllers
- [ ] **Interval Ear Training** — Structured interval recognition exercises
- [ ] **AI Composer** — Generate melody ideas using local model context
- [ ] **Cloud Sync (Opt-In)** — Optional encrypted backup of progress data
- [ ] **Transcription Mode** — Transcribe played melodies to sheet notation
- [ ] **Multi-Language AI Responses** — Expanded prompt localization

---

## 🔮 Long-Term Vision

> *Cross-platform music education platform*

- [ ] **Compose Multiplatform** — iOS and Desktop support
- [ ] **Lessons Marketplace** — Community-contributed lesson packs
- [ ] **AI Song Coach** — Full song learning with section-by-section feedback
- [ ] **Larger Model Support** — On-device 7B model support for high-RAM devices
- [ ] **Real-time Sheet Music** — Live score generation as you play
- [ ] **Band Practice Mode** — Multi-instrument session recording
